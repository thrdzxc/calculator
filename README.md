# AURORA — Premium Glass Calculator

A premium Flutter/Dart Android calculator with readable glassmorphism UI, responsive layout, animated hover and touch effects, dark/light modes, built-in Material icons, keyboard shortcuts, and a 30-item *session* calculation history.

## Features

- Frosted glass panels using real `BackdropFilter` blur and translucent layers.
- Mouse hover: glow, outline, and subtle scale; touch: press-down scale.
- High-contrast digits and mathematical operators in both themes.
- Plus, minus, multiply, divide, decimals, parentheses, negative numbers and percent.
- Proper precedence (`2 + 3 × 4 = 14`) and live result preview.
- Safe handling for invalid expressions and division by zero.
- Calculation history (last 30 calculations **in the current app session**) with restore and clear actions.
- Light/dark theme button and copy-to-clipboard icon.
- No third-party Flutter packages needed; only the Flutter SDK.

> **Note:** History and theme are stored in app memory for the current session, not permanently on disk.
>
> The Windows/macOS/web/iOS/Android platform scaffolds are deliberately generated by your local Flutter SDK so they match *your installed Flutter version* (3.47.8 in your setup). The core UI and logic are already provided.

## Step by step: Windows 11 + Android Studio

1. Download `AURORA_Glass_Calculator_Flutter.zip` and select **Extract All**.
2. Open the extracted `aurora_glass_calculator` folder.
3. **Double-click `SETUP_PROJECT.bat`.** This generates `android/` using your installed Flutter and resolves the app's dependencies.
4. Open **Android Studio** > **Open**, and select the `aurora_glass_calculator` folder (not the `lib` folder).
5. Let Android Studio finish indexing. Make sure the **Flutter** plugin (and Dart) are installed in Settings > Plugins.
6. Connect a phone with Developer options > USB debugging enabled, or start an Android emulator from Android Studio Device Manager.
7. In Android Studio Terminal, run `flutter devices`. Your phone/emulator should appear.
8. Choose your device and click **Run** (green triangle), or run `flutter run` from Terminal.
9. Use the app. If you want to run it again, double-click `RUN_APP.bat` (with a device connected).

If you prefer commands rather than the batch file, open CMD **inside the project folder** and run:

```cmd
flutter create --platforms=android .
flutter pub get
flutter doctor
flutter devices
flutter run
```

For Windows/Chrome previews, generate web support too with `flutter create --platforms=android,web .` and run `flutter run -d chrome`.

**Android SDK licenses:** If prompted, run `flutter doctor --android-licenses` and review/accept them.

## Tests

Inside the project directory, after `SETUP_PROJECT.bat` completes:

```cmd
flutter analyze
flutter test
```

The bundled unit tests cover precedence, decimals, percent, negative input, history, clear/delete, and division-by-zero behavior. The creator's environment did not have a Flutter SDK, so these tests must be run locally after the platform setup.

## Folder guide

- `lib/main.dart`: app, calculator UI, theme/history, keyboard controls.
- `lib/widgets/glass_key.dart`: animated glass number/operator buttons.
- `lib/core/calculator_engine.dart`: safe mathematical expression parser.
- `lib/core/calculator_controller.dart`: calculator state and input logic.
- `test/`: engine and input/controller tests.
- `SETUP_PROJECT.bat`: first-time setup on Windows.
- `RUN_APP.bat`: run on a connected Android phone/emulator.

## Troubleshooting

- **`flutter` not recognized:** Close/reopen CMD; check `C:\develop\flutter\bin` is in the User PATH.
- **No devices:** Enable USB debugging, authorize the PC on your phone, or launch an Android emulator.
- **Android license error:** `flutter doctor --android-licenses`.
- **Build errors:** Ensure Android Studio installed the Android SDK Platform, Android SDK Command-line Tools and Platform-Tools; run `flutter doctor -v`.
- **Missing `android/` folder:** Run `SETUP_PROJECT.bat` before opening/running the app.
